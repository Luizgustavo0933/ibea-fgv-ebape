# IBEA × FGV EBAPE — Site institucional (protótipo)

Site estático de apresentação do International Business Education Alliance (IBEA), com:

- **Your IBEA Journey** interativo;
- imagens institucionais da FGV EBAPE e das instituições parceiras;
- galeria da comunidade IBEA e formatura de 2025;
- área **Student Voices** com espaços reservados para futuros depoimentos verdadeiros;
- alternância entre inglês e português.

## Publicar pelo GitHub Pages

1. Crie um repositório, por exemplo `ibea-fgv-ebape`.
2. Carregue o conteúdo **desta pasta** na raiz do repositório, mantendo `index.html`, `.nojekyll` e a pasta `assets` juntos.
3. Na aba **Settings > Pages**, em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)` e clique em **Save**.
5. O endereço normalmente será `https://SEU-USUARIO.github.io/ibea-fgv-ebape/`.

## Antes de divulgação oficial

- Confirme autorização institucional para o uso das marcas FGV EBAPE e IBEA.
- Confirme autorização de uso de imagem das pessoas fotografadas e direitos das fotografias fornecidas.
- A seção **Student Voices** contém apenas sugestões de perguntas, **não depoimentos reais**. Substitua-as por testemunhos autorizados.
- Valide regras de admissão e informações institucionais com a equipe responsável.

Este projeto é um **protótipo** e não representa publicação oficial da FGV.

## Conteúdo técnico

Site estático HTML, CSS e JavaScript, sem framework ou dependência de internet para carregar as fotografias. Todos os caminhos de mídia são relativos para permitir publicação em um subdiretório do GitHub Pages.
